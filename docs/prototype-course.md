# 시범 코스 — 4층 12학년 (바닥 검정 선 붙이는 법)

앱의 로봇 주행 계획은 `public/js/data.js` 의 `robotCourse` 선 위에서만 계산됩니다.
바닥 테이프를 **아래 그림·길이 그대로** 붙이면 앱 지도(4층 도면)와 로봇이 같은 길을 갑니다.
도면을 1단위 = 2cm 로 줄였고, 반으로 들어가는 가지 선은 40cm 로 통일했습니다.

```
                 12-3       12-2        12-1
                ━━┳━━      ━━┳━━       ━━┳━━      ← 끝 가로선(20cm) = 반 앞 (도착하는 곳)
                  ┃          ┃           ┃        ← 가지 선 40cm
  ━━━━━━━┳━━━━━━━━┻━━━━━━━━━━┻━━━━━━━━━━━┻━━━━━━   ← 가로 복도 선
   20cm  ┃ 꺾이는 곳 41cm      51cm        61cm   20cm
         ┃
         ┃ 52cm
  ┃      ┃
  ┣━━━━━━┫ 12-4 갈림길                             ← 12-4 가지 선 40cm (왼쪽으로)
  ┃      ┃
  12-4   ┃ 83cm
         ┃
  ┃      ┃
  ┣━━━━━━┫ 12-5 갈림길                             ← 12-5 가지 선 40cm (왼쪽으로)
  ┃ 🤖→  ┃
  12-5   ┃ 20cm (갈림길 아래로 더)
  (출발)
```

## 붙이는 순서

1. **세로 선** (세로 복도): 아래에서 위로 20cm + 83cm + 52cm = **155cm**.
   - 아래 끝에서 20cm 지점 = 12-5 갈림길, 거기서 83cm 위 = 12-4 갈림길, 거기서 52cm 위 = 꺾이는 곳.
2. **가로 선** (가로 복도): 꺾이는 곳 왼쪽으로 20cm 더 나가게 시작해서 오른쪽으로 20cm + 41cm + 51cm + 61cm + 20cm = **193cm**.
   - 꺾이는 곳에서 오른쪽으로 41cm = 12-3 갈림길, 51cm 더 = 12-2, 61cm 더 = 12-1, 그리고 20cm 더 붙여 끝냄.
3. **가지 선 5개** (각 40cm):
   - 12-5, 12-4: 세로 선에서 **왼쪽**으로
   - 12-3, 12-2, 12-1: 가로 선에서 **위쪽**으로
4. **끝 가로선 5개** (각 20cm): 가지 선 끝에 T 자로. 로봇은 이 가로선을 보고 "도착" 을 압니다.

- 모든 갈림길은 T 또는 ㅓ 모양이어야 합니다 (그래서 꺾이는 곳·12-5 갈림길·12-1 갈림길 너머로 20cm 씩 더 붙임).
- 갈림길끼리는 40cm 이상 떨어져 있어야 로봇이 하나씩 알아봅니다.

## 로봇 놓기

- 제자리 = **12-5 가지 선 끝**. 끝 가로선 바로 앞에, **세로 선 쪽(오른쪽, 도면의 동쪽)을 보게** 놓습니다 (펌웨어 `HOME_HEADING 'E'`).
- 목적지에 도착하면 끝 가로선 앞에서 멈추고, 다음 출발 때 제자리에서 유턴해서 나옵니다.

## 길이를 바꾸고 싶으면

`data.js` 의 `robotCourse.nodes` 좌표(4층 도면 좌표)를 바꾸면 앱 계획이 따라 바뀝니다.
바닥 길이 = 도면 거리 × 2cm. 왼쪽/오른쪽 회전은 모양(좌표)으로 계산하므로 바닥 모양만 도면과 같으면 됩니다.
