# 시범 코스 — 4층 12학년 (바닥 검정 선 붙이는 법)

앱의 로봇 주행 계획은 `public/js/data.js` 의 `robotCourse` 선 위에서만 계산됩니다.
바닥 테이프를 **아래 그림·길이 그대로** 붙이면 앱 지도(4층 도면)와 로봇이 같은 길을 갑니다.
도면을 1단위 = 2cm 로 줄였고, 반으로 들어가는 가지 선은 40cm 로 통일했습니다.

```
                 12-3       12-2        12-1
                ━━┳━━      ━━┳━━       ━━┳━━      ← 끝 가로선(20cm) = 반 앞 (도착하는 곳)
                  ┃          ┃           ┃        ← 가지 선 40cm
         ┏━━━━━━━━┻━━━━━━━━━━┻━━━━━━━━━━━┛        ← 가로 복도 선 (12-1 에서 ㄱ 으로 꺾임)
         ┃ 꺾이는 곳 41cm      51cm        61cm
         ┃
         ┃ 52cm
  ┃      ┃
  ┣━━━━━━┫ 12-4 갈림길                             ← 12-4 가지 선 40cm (왼쪽으로)
  ┃      ┃
  12-4   ┃ 83cm
         ┃
  ┃      ┃
  ┣━━━━━━┛ 12-5 (ㄱ 으로 꺾임)                      ← 12-5 가지 선 40cm
  ┃ 🤖→
  12-5
  (출발)
```

(사용자 그림대로: 12-5 · 위 꺾이는 곳 · 12-1 은 선을 더 내지 않고 ㄱ 으로 꺾음. 휴대폰으로 찍은 그림은 180° 돌아가 있음)

## 붙이는 순서

1. **세로 선**: 12-5 꺾이는 곳에서 위로 83cm = 12-4 갈림길, 52cm 더 = 위 꺾이는 곳 (모두 **135cm**).
2. **가로 선**: 위 꺾이는 곳에서 오른쪽으로 41cm = 12-3 갈림길, 51cm 더 = 12-2, 61cm 더 = 12-1 꺾이는 곳 (모두 **153cm**).
3. **가지 선 5개** (각 40cm): 12-5·12-4 는 세로 선에서 왼쪽으로(12-5 는 세로 선 아래 끝에서 꺾임), 12-3·12-2 는 가로 선에서 위로, 12-1 은 가로 선 끝에서 위로 꺾임.
4. **끝 가로선 5개** (각 20cm): 가지 선 끝에 T 자로. 로봇은 이 가로선을 보고 "도착" 을 압니다.

- 꺾이는 곳(ㄱ)도 로봇은 한쪽 뒤 센서로 갈림길처럼 알아보고, 앱 계획이 그쪽으로 돌라고 알려 줍니다.
  꺾이는 곳에서 선을 놓치면 그 꺾이는 곳 너머로 선을 10~20cm 더 붙여 T 모양으로 만들면 됩니다 (앱 쪽은 바꿀 것 없음).
- 길이는 정확하지 않아도 됩니다. **순서와 모양(왼쪽/위쪽)** 이 같으면 되고, 갈림길끼리 40cm 이상만 떨어뜨려 주세요.

## 로봇 놓기

- 제자리 = **12-5 가지 선 끝**. 끝 가로선 바로 앞에, **세로 선 쪽(오른쪽, 도면의 동쪽)을 보게** 놓습니다 (펌웨어 `HOME_HEADING 'E'`).
- 목적지에 도착하면 끝 가로선 앞에서 멈추고, 다음 출발 때 제자리에서 유턴해서 나옵니다.

## 길이를 바꾸고 싶으면

`data.js` 의 `robotCourse.nodes` 좌표(4층 도면 좌표)를 바꾸면 앱 계획이 따라 바뀝니다.
바닥 길이 = 도면 거리 × 2cm. 왼쪽/오른쪽 회전은 모양(좌표)으로 계산하므로 바닥 모양만 도면과 같으면 됩니다.
